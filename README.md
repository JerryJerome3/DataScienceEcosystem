# Data Science Coursework and Projects

This repository contains selected projects and exercises completed while developing practical skills in data analysis, Python, and machine learning.

## Featured project: King County House Price Analysis

**Notebook:** [RealEstate.ipynb](RealEstate.ipynb)

An exploratory data analysis and regression modeling project using the King County housing dataset provided through IBM Skills Network coursework.

The notebook covers:
- Data inspection, cleaning, and missing-value handling
- Exploratory analysis of sale prices and property characteristics
- Visualizations of relationships between home features and prices
- Mean baseline, linear regression, and Ridge regression
- Train/test evaluation using MAE, RMSE, and R-squared
- Cross-validation and model error inspection
- Business interpretation and project limitations

## Tools and technologies
- Python, Pandas, and NumPy
- Matplotlib and Seaborn
- scikit-learn
- Jupyter Notebook / Google Colab
- Regression modeling and model evaluation

## How to run
1. Open a notebook in GitHub and select **Open in Colab**, or download it and upload it to Google Colab.
2. Run cells from top to bottom.
3. The housing notebook downloads its dataset from the IBM Skills Network course data URL included in the notebook.

## Data limitations
The housing dataset is historical and educational. It is not a live real-estate feed and should not be used as a current property valuation tool. Model metrics should be regenerated by running the notebook.
